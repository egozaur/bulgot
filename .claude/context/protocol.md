# Protokół serwera Bulgota (`/api/bg/*`)

Przeniesione 1:1 z dawnego `CLAUDE.md` (2026-11-24). Czytaj tylko przy pracy nad akcjami serwera lub `api.js`/`act()` w kliencie. Kod: `../pl3y-server/src/games/bulgot/player.js` (`BgPlayer.handle`, `switch` po akcji), logika w `rules.js`.

`state`, `start {mode,char,garnek,curses?}` (z Nemezis i Testamentem z profilu; `curses` = do 3 id z `CURSES`, zły zestaw = 400 `curses`), `pick {i,slot?,mut?}`, `buy {i,slot?,mut?}` (dokup kafelek z oferty za Ziarna; cena wg rzadkości w `RULES.prices`, wolny wybór zostaje), `reroll`, `rest`, `shop {i}` (-1 = wyjdź), `history` (TESTOWA historia ostatnich 30 runów z dziennikiem rund; do usunięcia po testach), `bet {amount}`, `bonus {i,slot?,mut?}`, `choose {i}` (trasa w fazie `route`, Dogrywka/koniec w fazie `victory` (0 = dalej, 1 = koniec), adopcja towarzysza (`event`/`adopt`, -1 = rezygnacja), Arena (`event`/`arena`, 0 = walka, 1 = odwrót), Odznaka w fazie `badge`, łup z bossa w fazie `loot` (odpowiedź `looted`), drzwi w fazie `door`, Kontrakt z HR i Kapliczka w fazie `event`), `pawn {id}` i `redeem` (Lombard Lisa, faza `offer`), `upgrade {id}` (Ulepszanie: 3 kopie statystyki poziomu 1/2 → 1 kafelek następnego poziomu, faza `offer`; błędy `phase|index|level|copies`), `will {i}` (Testament po przegranej; `-1` = bez testamentu), `fightstart` (zwraca `setup` z ziarnem walki), `fightfinish {inputs}`, `abandon`, `kurnik {id}` (kupno poziomu budynku Kurnika za Pióra, tylko od 20. poziomu Stażu, inaczej kod `locked`; profil niesie `kurnikOpen` i `kurnikNeed`; błędy `index|max|feathers`), `code {text}` (hasło do ukrytej postaci; błędne = 409 `code`), `skillorder {a,b}` (zamiana slotów umiejętności przed walką; sloty = klawisze 1/2/3), `analysis {id, note?, tags?}` („Wyślij do analizy”: serwer kopiuje wpis historii tego runu do kolekcji w `BgRanks`; raz na run; `note` ≤ 300 znaków, `tags` ≤ 6 po ≤ 24 znaki). Odpowiedź: `{ok, profile, run, ...}` albo `{err, code}` (400/409; 401 gdy brak sesji lub nicka). `GET /api/bg/ranks?mode=quick|full[&char=<id>][&garnek=<n>][&nick=<nick>][&kind=deep]` (`kind=deep` = ranking Dogrywki wg pięter ponad limit) (filtry opcjonalne; bez nich ranking ogólny, jeden wpis na gracza). Opis stanu: `rules.js` → `view()`.

Opis widoku stanu dla klienta: `rules.js` → `view()` (nie zdradza `seed`). Patch 1.1: `upgrade {id, hot?}` (hot = przegrzany zlew poziomu 2 → 3), `view().preview` (zmiana statystyk po wzięciu kafelka z oferty), brak fazy `door` i akcji `bonus {i:-1}`.

## Pojedynek dla 2 osób (`duel`, `start { duel: true }`)

`duel { op, code?, vote? }` (BgPlayer przekazuje do BgRanks `/duel-op`; błąd = 409 z `code`): `create` (kod 5 znaków `A-HJ-NP-Z2-9`, wznawia trwający mecz), `join { code }`, `vote { vote: { char, garnek } }` (tylko w stanie `vote`), `state` (odczyt i przejścia zależne od czasu), `leave` (wyjście z meczu). Odpowiedź ma `duel` = widok meczu: `{ code, state: lobby|vote|play|done, now, voteDl, startAt, cfg: { char, garnek, charForced, garnekForced, pool }, me, rival: { nick, voted, vote, prog }, result }` (cudzy głos jawny dopiero po głosowaniu; `rival.prog.dealt` dopiero po końcu; bez soli ziarna). Kody błędów: `active` (trwa zwykły run albo inny mecz), `nocode`, `full`, `phase`, `vote`, `none`.
`start { duel: true }` (stan `play` i po `startAt`; jeden raz na mecz) tworzy run: tryb Szybki, pula startowa, postać i palnik z `cfg`, ziarno z soli meczu, bez Kurnika i premii. Run ma `run.duel = { code, dl, sk, dealt, pl }`; odpowiedzi mają `duelRun = { code, dl, dealt, now }` (termin w czasie serwera). **Terminy:** 60 s na wszystkie decyzje po walce (`decide`), 15 s na start walki (`wait`), walka do `MAX_TICKS`+60 s (`fighting`). Po terminie (+1,5 s) serwer sam decyduje (`duel.js` `autoStep`: bezpieczne wybory, walka bez wejść; czas wirtualny, więc długa nieobecność rozlicza się w jednym żądaniu), zapis robi też budzik DO (`alarm()`). Prezes pokonany = wygrana (bez Dogrywki). Zwycięzca: więcej wygranych pięter, potem więcej zadanych obrażeń (`run.duel.dealt`, suma `result.dealt`); koniec, gdy oboje skończyli albo jedno skończyło, a drugie ma już więcej pięter. Wynik nie wchodzi do profilu, rankingu, historii ani odblokowań.
